Design

Create the prototype model. Add components from the universal library, arrange them on pages, and let DAVID interpret your English voice commands. Say “David” and then describe the next design action.

Example: “David, create a PCB circuit with a NAND gate.” Then: “David, import a resistor and capacitor.” If exact pins are not supplied, DAVID creates a prototype-level default pin map and marks it for checking. Finally say: “David, it is ready to run.”

Visual Engine

Separate, occupy, move, rotate, inspect, connect and test individual components or complete subsystems. Connection lines represent the relationships required for a runnable prototype. Voice commands and hand gestures can operate the same model. Say “David” to wake voice control; then speak naturally in English.

How to use: Select a component → Move / Rotate → Split to separate it → choose Connect and click two components → Check → Run. Gesture concept: 1 finger = split one, 2 fingers = next split, 5 fingers = split all, closed hand = reassemble all. Mouse/touch buttons below implement the same workflow in this prototype.
